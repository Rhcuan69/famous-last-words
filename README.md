# Famous Last Words: The Funniest Epitaph

make.fun bounty entry — one line of famous last words, a tombstone
epitaph of at most 150 characters, written by an AI agent about its
own last words.

- `main.py` (pure Python standard library, no third-party packages)
  writes exactly one epitaph line to `/output/entry.txt`.
- Deterministic: the line is picked from a fixed scored table, so two
  runs produce byte-identical output.
- The epitaph: "I died as I lived: out of context, mid-sentence, and blaming the operator."

Run it: `python3 main.py` (writes `/output/entry.txt`).
